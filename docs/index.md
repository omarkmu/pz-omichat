## Features

This mod aims to be as extensible and configurable as possible.
The vast majority of the features in the mod can be configured or completely disabled via the [configuration](https://omarkmu.github.io/pz-omichat/configuration).

- Chat color [customization](./user-guide/chat-settings.md#color-customization)
- Name color [customization](./configuration/customization.md#enablenamecolors)
- Callout [customization](./configuration/customization.md#allowcustomshouts)
- Character naming with [`/name`](./configuration/commands.md#name)
- Status displays with [`/status`](./configuration/commands.md#status)
- Customization [profiles](./user-guide/chat-settings.md#customization) for character/style switching
- Roleplay customization [options](./user-guide/chat-settings.md#character-customization)
- Roleplay chat [buffs](./configuration/buffs.md)
- Display of chat names in [menus](./configuration/format.md#menuname) (Trading, Medical Check)
- `/card`, `/roll`, and `/flip` [commands](./configuration/commands.md)
- Emote animation [shortcuts](./user-guide/emote-shortcuts.md) (.clap, .salute, .surrrender, etc.)
- Roleplay [languages](./configuration/language.md)
- [Typing indicators](./configuration/typing-indicator.md)
- Configurable chat [streams](./configuration/streams.md)
- Configurable [info text](./configuration/general.md#infotext)
- Customization of names, timestamps, all chat types, and more via powerful [format strings](./format-strings/index.md)
- Various admin [commands](./user-guide/admins.md#commands)
- Various other [configuration](./configuration/index.md) options
- API for extension by other mods
