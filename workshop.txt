description=[h2]Description[/h2]
description=OmiChat improves the chat for players and offers many configuration options for server operators. Among other features, it includes color customization, character naming, emote shortcuts, and new chat commands for roleplay.
description=
description=Chat streams can be customized by admins, but many are available with the default settings: [list]
description=[*]/all
description=[*]/faction [/f]
description=[*]/safehouse [/sh]
description=[*]/pm (private chat; replaces vanilla /whisper)
description=[*]/say [/s]
description=[*]/yell [/y]
description=[*]/low (short range chat)
description=[*]/whisper [/w] (shorter range chat)
description=[*]/me [/m] (describes a character's actions)
description=[*]/meloud [/ml]
description=[*]/mequiet [/mq]
description=[*]/mewhisper [/mw]
description=[*]/do [/d] (describes an action or event)
description=[*]/doloud [/dl]
description=[*]/doquiet [/dq]
description=[*]/dowhisper [/dw]
description=[*]/ooc [/o] (local out-of-character chat)
description=[*]/admin [/a] (admin-only chat)
description=[/list]

description=For more details, please see the [url=https://omarkmu.github.io/pz-omichat]documentation![/url]

description=[h2]Features[/h2]
description=This mod aims to be as configurable as possible. The vast majority of the features listed below can be configured or completely disabled via the configuration.
description=
description=The default settings, based on buffy's roleplay chat, are tailored to usage for roleplay. Presets are also available for lighter RP and for mimicking vanilla.
description=
description=[b]Features for players:[/b] [list]
description=[*]Chat color customization
description=[*]Speech bubble color customization
description=[*]Callout customization
description=[*]Character naming with /name
description=[*]Profiles for character switching
description=[*]Character customization options (grow hair/beard, change hair color)
description=[*]Roleplay chat buffs
description=[*]/card, /roll, and /flip commands
description=[*]Roleplay descriptions with /me and /do (and counterparts with larger and smaller ranges)
description=[*]Display of chat names in menus (Trading, Medical Check)
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2648779556]True Actions Act 3 - Dancing[/url] compatibility with /dance (currently disabled)
description=[*]Input suggestion box
description=[*]Emote animation shortcuts (.clap, .salute, .surrender, etc.) + /emotes command to display a list of emotes
description=[*]Roleplay languages
description=[*]Typing indicators (off by default)
description=[*]...and more!
description=[/list]
description=
description=[b]Features for server operators:[/b] [list]
description=[*]Various admin commands
description=[*]Configurable chat streams
description=[*]Configurable info text
description=[*]Configurable roleplay languages
description=[*]Customization of names, timestamps, all chat types, and more via powerful chat formats
description=[*]Configuration menu to control the features listed above in-game, including pre-made presets
description=[*]Further extension of functionality using the API
description=[/list]
description=

description=
description=Compatibility patches for other mods are included, but the relevant options are disabled since not everything is upgraded to b42.
